## 技術說明

### 環境變數設定架構

Vite 的 env 載入邏輯（`envDir: '.env'`）：

```mermaid
flowchart LR
    subgraph dev["npm run dev（--mode dev）"]
        E1[".env/.env<br>（正式設定）"] --> M1["merge"]
        E2[".env/.env.dev<br>（開發覆蓋）"] --> M1
        M1 --> D1["VITE_API_BASE_URL=''<br>→ Vite proxy → localhost:8001"]
    end

    subgraph prod["npm run build（--mode prod）"]
        E3[".env/.env<br>（正式設定）"] --> D2["VITE_API_BASE_URL=http://10.16.93.48:8001<br>→ 直連後端"]
    end
```

- `.env/.env`：正式環境設定，`VITE_API_BASE_URL=http://10.16.93.48:8001`
- `.env/.env.dev`：開發覆蓋，`VITE_API_BASE_URL=`（空字串，走 Vite proxy）
- `vite.config.ts`：加入 `envDir: '.env'`，以 `loadEnv` 讀取 `DEV_API_TARGET` 設定 proxy target

### IIS SPA 路由設定

SPA（Single Page Application）所有路由都由前端 React Router 處理，IIS 預設會對非根目錄的 URL 回傳 404。`public/web.config` 加入 URL Rewrite 規則解決此問題：

```mermaid
flowchart TD
    A["瀏覽器請求 /dashboard"] --> B{"是靜態檔案？"}
    B -- 是 --> C["IIS 直接回傳靜態檔案"]
    B -- 否 --> D["URL Rewrite：重寫至 /"]
    D --> E["回傳 index.html"]
    E --> F["React Router 接管路由"]
```

**web.config 主要規則：**
- `SPA Routes`：非靜態檔案 → rewrite 到 `/`（index.html）
- `API Reverse Proxy`（選用 Option B）：`/api/*` → proxy 到 `localhost:8001`

```mermaid
        B3["瀏覽器"] -->|"靜態檔案 + /api/*"| IIS2["IIS（port 5001）"]
        IIS2 -->|"proxy /api/*"| BE3["後端 FastAPI<br>localhost:8001"]
    end
```
