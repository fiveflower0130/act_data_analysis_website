## 技術說明

### 雙主題資料流

- Netlist：`Upload.Dragger` 接受 `.xlsx`，以 `FormData(file)` 呼叫
  `POST /api/v1/netlist/upload`
- Fail Sample：`Upload.Dragger` 接受 `.json`，先以 `File.text()`／`FileReader`
  讀取並 `JSON.parse()`，再以 raw JSON body 呼叫
  `POST /api/v1/data/fail-sample-import/upload`，並帶入 `source_file`
- Fail Sample 清單固定查詢最新 50 筆，再對 `lot_id`／`test_program` 做前端過濾，
  因後端端點沒有 `test_program` query parameter

### 佇列與權限

- `uploadStore` 管理主題、兩份清單快取、佇列與每筆待上傳／上傳中／成功／失敗狀態
- JSON 解析失敗不呼叫 API；HTTP 失敗保留 status code，所有失敗項目不提供重試
- 切換主題會清空佇列，避免不同檔案類型送往錯誤 API
- `/upload` 僅允許 `engineer`／`admin`；`viewer` 導向 `/dashboard`，Navbar 同步隱藏入口
- Netlist／Fail Sample 清單的 `uploaded_by` 現為上傳者工號；頁面直接顯示工號，
  `null` 顯示「—」，不查詢 `/users`
- Fail Sample 上傳成功後依格式 A/B payload 的 `lot_id`／`hbin` 清除 Dashboard 對應
  Lot 的 IO／POWER 快取
